
# CityLink-SCP

CityLink-SCP is a portal MVP developed for CityLink Initiatives to improve citizen engagement and provide easier access to community information, events, and services. This website provides users with a central platform that allows them to:
- view announcements, events, and services
- book community events and services
- manage bookings
- send feedback and enquiries

Authorised staff or admin users can also manage site content, users, and bookings through a dedicated Staff Portal and XML configurations.



## Features
Community User Features
- User Registration & Login
- Community Announcements
- Event Browsing & Booking
- Service Information & Bookings
- Frequently Asked Questions (FAQs)
- Feedback & Enquiries Submission

Admin/Staff User Features
- Staff Authentication and Authorisation
- Content Management via XML-based Configuration
- User Management
- Event Management
- Booking Management
- Feedback Monitoring
